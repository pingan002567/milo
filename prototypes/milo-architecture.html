Milo · 初版总体架构

MVP 小组模式 · 轻量化 embedded-first · 组长 → 秘书长 → 组员（≤5 并行） · 2026-07-18

技术栈

  • • 壳：Tauri 2 + React 18 + TS + Tailwind（备选 Electron）
  • • 后端：Python 3.12 + FastAPI + Pydantic v2 + asyncio
  • • 存储：SQLite (WAL) + 本地 artifacts 目录
  • • 密钥：keyring（Keychain / DPAPI）
  • • Schema：JSON Schema 单一来源（org / pack / 信封 / 事件）
  • • DeerFlow：git 依赖 pin tag（subdirectory=backend/packages/harness）

轻量化决策

  • • embedded-first：milod 单进程内跑 N 个 DeerFlowClient
  • • plan_mode=True 直接复用为"计划前置授权"
  • • 隔离降级为目录级（弱隔离明示，lint 警告高危组合）
  • • Registry v0 = Git 仓库 + index.json，不建服务端
  • • 调度用 asyncio 单进程（并行 ≤5 护栏反哺工程简化）
  • • ContainerAdapter 为同接口第二实现，后补不返工

里程碑

  • • M0 Spike（2 周）：escalate 事件形态第一优先 + SDK 可安装性
  • • M1 CLI 闭环（~2 周）：招募→派单→三槽位→交付验收
  • • M2 秘书长+任务群（4 周）：多成员并行 · 超时链 · 事件回放
  • • M3 桌面壳 ∥ M4 Pack+Registry（各 4 周并行）
  • • 合计 ~12 周到 MVP 交付线
